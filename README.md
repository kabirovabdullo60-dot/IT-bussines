# 🚀 INNOMA.VC — Responsive Single-Page Landing

🌐 **INNOMA.VC** — это современный, полностью адаптивный одностраничный лендинг (Landing Page), разработанный для международного аналитического агентства, которое помогает IT-бизнесу и стартапам запускаться на рынках Азии, Ближнего Востока, Латинской Америки и Африки.

Данный интерфейс объединяет все ключевые секции сайта в единую, оптимизированную структуру без дублирования элементов (no clones), гарантируя высокую производительность и точность отображения на любых типах устройств.

---

## 🛠️ Технологический стек (Tech Stack)

* **HTML5** — семантическая разметка для хорошей читаемости кода и SEO.
* **Tailwind CSS** — утилитарный CSS-фреймворк для быстрой и гибкой адаптивной стилизации.
* **CSS Flexbox & Grid** — построение современных сеток и гибких выравниваний элементов.
* **Responsive Layout** — кастомная адаптивность под мобильные телефоны, планшеты и десктопы.

---

## ✨ Особенности адаптивности (Responsive Features)

Интерфейс спроектирован с учетом трех ключевых состояний экрана:

* **💻 Desktop / Ноутбук (`lg:`)**
  * Классическое горизонтальное расположение блоков (изображения и текст находятся рядом).
  * Четкие фиксированные сетки на 3, 4 и 5 колонок для галерей и карточек событий.
  * Интерактивные кнопки навигации (стрелки) для слайдеров.

* **📱 Tablet / Планшет (включая iPad Pro 11 — `md:`)**
  * Центрированное текстовое содержимое для удобства чтения.
  * Активирован плавный **горизонтальный скролл** (`overflow-x-auto`) для секции экспертов, что делает тач-взаимодействие более нативным.

* **📲 Mobile / Телефон (`sm:`)**
  * Полностью вертикальная ориентация основных информационных блоков.
  * Горизонтальный скролл (`overflow-x-auto`) для галереи, карточек экспертов и блока мероприятий с эффектом магнитной фиксации элементов (`snap-x snap-mandatory`).
  * Скрытие громоздких элементов управления (стрелок слайдера), замененное на удобный жестовый скролл.

## 📂 Структура кода лендинга (Page Sections)

Файл содержит следующие последовательные секции:
1. **Кто мы?** — Промо-блок с адаптивным отображением интерфейса платформы.
2. **Основатель** — Персональная карточка Романа Гайна (с автоматическим переключением текста в курсив на мобильных устройствах).
3. **Галерея** — Компактный ряд изображений со скроллом на мобильных и grid-сеткой на десктопе.
4. **Эксперты программы** — Горизонтальная карусель специалистов с адаптивными кнопками.
5. **Call to Action (Banner)** — Мотивационный блок со стильной темной подложкой (`bg-black/65`), фоновым рисунком и градиентной кнопкой.
6. **Мероприятия и события** — Сетка карточек с автоматическим выравниванием высоты под разную длину текста.
7. **Форма связи** — Интерактивная форма заявки со встроенным выбором кода страны и быстрыми ссылками на мессенджеры (Telegram, WhatsApp).
